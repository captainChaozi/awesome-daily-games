# Contributing

Thank you for helping improve Awesome Daily Games.

## Add a game

A game must:

- publish a substantially shared challenge every day;
- be playable on the public web;
- have an identifiable official URL;
- have a concise, original description;
- fit one primary category.

Open an issue or pull request with the game name, official URL, description, category, and evidence that it updates daily.

## Correct or remove a game

Report broken links, cadence changes, duplicate entries, ownership changes, misleading descriptions, or unsafe redirects. Games that are no longer daily or publicly playable will be removed.

## Recommended and Popular placement

Normal submissions do not automatically enter Recommended, Essential, or Popular Right Now. Those placements require a separate editorial review. Popular Right Now also requires dated public-interest evidence.

## Writing style

Describe what the player does. Do not copy another directory, use promotional superlatives, invent popularity, or add affiliate and tracking parameters.
